# 🚀 ViralMind AI - Social Media Growth & Virality Engine

An autonomous AI Agent web platform designed to analyze company social media profiles (YouTube, Instagram, Facebook, Twitter/X, and Google Business Profile), autonomously research trending topics, predict virality scores, decode subconscious consumer psychology, craft high-retention hooks and storytelling scripts, and recommend platform-specific optimal posting schedules.

## 🌟 Key Features

1. **Autonomous Trend Hunter & Manual Topic Studio**:
   - Researches high-velocity trending topics in real time.
   - Enter manual topic ideas with support for **Video Mode** (Reels, Shorts, Videos) and **Photo/Carousel Mode** (High-save Infographics).

2. **Virality Predictor & Step-by-Step Blueprint**:
   - **0-100% Virality Score** & Confidence metrics.
   - Actionable 4-step execution checklist to trigger the algorithm distribution multipliers.

3. **Subconscious Mind & Psychological Trigger Matrix**:
   - Decodes Dopamine Spikes, Curiosity Gaps, FOMO / Loss Aversion, and Identity Elevation.
   - 5-stage storytelling overhaul framework (Pattern Interrupt, Agitation, Secret Mechanism, Transformation Proof, Subconscious CTA).

4. **Hook & Multi-Platform Copy Studio**:
   - 5 Tested Hooks with specific **Visual Cues** and **Audio SFX**.
   - Scene-by-scene script generator with timestamps and voiceovers.
   - Platform-adapted copy for **YouTube, Instagram, Facebook, Twitter/X, and Google Business Profile**.

5. **5-Platform Optimal Timing & Heatmaps**:
   - Hourly engagement distribution heatmaps across all days of the week.
   - Algorithm secrets and best time slot recommendations.

6. **Social Profile URL Auditor**:
   - Ingest YouTube, Instagram, Facebook, Twitter, and Google Business Profile URLs one-by-one.
   - Comprehensive SEO & branding scores, bottleneck identification, AI bio rewrite, and 30-day viral roadmap.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, Lucide Icons, Framer Motion
- **Backend**: Node.js, Express, Axios, Dotenv
- **AI Intelligence**: Google Gemini API integration with fallback intelligent heuristic engine

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server (Frontend + Backend)
```bash
npm run dev
```
- Frontend will be available at `http://localhost:5173`
- Backend API will run at `http://localhost:5000`

### 3. Build for Production
```bash
npm run build
```
